# Adding project images

Each project folder has an `images/` folder. To add screens:

1. Export frames from Figma (PNG, 2x) or download them from the Upwork project.
2. Name them in order, e.g. `01-home.png`, `02-details.png`.
3. Drop them in that project's `images/` folder.
4. In the project's README, replace the line under **Screens** with `![Home](images/01-home.png)` lines.
5. Optional: replace `cover.svg` with a real cover image and update the image path in the main README.
