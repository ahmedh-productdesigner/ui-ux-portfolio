# Flight Booking – Landing Page

![Flight Booking – Landing Page – landing page and website UI/UX design by Muhammad Ahmed Hussain](cover.svg)

**Category:** Landing Pages & Websites · **Type:** Website · Travel · **Tool:** Figma

A travel and flight booking site with search front and centre.

## The challenge

Travellers come to search. Everything else on the page needed to support that one action.

## What I designed

- Flight search widget
- Popular destinations and deals
- Booking steps
- Responsive layouts

## Approach

Search-first hero, destination imagery for inspiration and simple, scannable deal cards.
