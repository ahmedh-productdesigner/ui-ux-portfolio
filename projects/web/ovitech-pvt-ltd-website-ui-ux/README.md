# OviTech (Pvt) Ltd – Website UI/UX

Company website UI/UX for OviTech, an IT and software services company, designed while working in-house.

## The challenge

The company needed a modern website that explains a wide range of IT services without overwhelming visitors.

## What I designed

- Homepage
- Service and solution pages
- Portfolio / clients
- Careers and contact

## Approach

Organised services into clear groups and gave each a consistent page template.
