# Casino Gaming Mobile App UI

![Casino Gaming Mobile App UI – mobile app UI/UX design by Muhammad Ahmed Hussain](cover.svg)

**Category:** Mobile App Design · **Type:** Mobile · Gaming · **Tool:** Figma

A high-energy game lobby and gameplay UI for a mobile casino-style game.

## The challenge

Gaming UI needs excitement without clutter, and rewards that are easy to understand.

## What I designed

- Game lobby
- Rewards and bonus screens
- Wallet and coins
- Profile and leaderboards

## Approach

Bold colour, depth and motion-ready components, with clear hierarchy so players always know where to tap.
