# Real Estate Mobile App (Hously)

![Real Estate Mobile App (Hously) – mobile app UI/UX design by Muhammad Ahmed Hussain](cover.svg)

**Category:** Mobile App Design · **Type:** iOS & Android · Property · **Tool:** Figma

A property browsing app built around fast search, rich listing pages and an easy way to contact the agent.

## The challenge

Buyers compare a lot of listings. The design needed to make scanning, saving and comparing properties effortless.

## What I designed

- Search with location, price and type filters
- Listing cards and detailed property page
- Saved homes and favourites
- Agent contact and booking a viewing

## Approach

Image-first listing cards, key facts surfaced above the fold and a sticky contact action on every detail page.
